## 功能一览（v0.9.9）

| # | 功能 |
|---|---|
| 1 | 侧边栏价格页：按分组管理中转站 / 模型，五项单价（输入 / 缓存读取 / 缓存写入 / 输出 / 按次） |
| 2 | 长按消息 →「这条花了多少」 |
| 3 | 长按消息 →「本对话花了多少」 |
| 4 | 按次计费（读数据库数请求次数） |
| 5 | **自动匹配价格**（先中转站名、再模型名，宽松容错） |
| 6 | **从软件同步中转站**（读 Operit 配置一键导入 + 勾选面板） |
| 7 | 分组 + 三级调序（分组 / 组内中转站 / 中转站内模型） |
| 8 | 模型默认折叠，点标题展开才看价格（折叠时显示价格概览） |
| 9 | 同步面板：新中转站在上、已导入的沉底并标注「可补 N 个新模型」 |

## 四句话记住核心

1. **它是个纯本地计算器**，不联网、不耗 token。
2. **token 用量来自消息对象，请求次数来自本地数据库**（时间窗圈选）。
3. **价格自动匹配规则：先对中转站名，再对模型名**（宽松容错，对不上就跳过并提示）。
4. **这个平台的 Compose DSL 只支持"单击"交互**——没有动画、没有长按、没有拖动。
   所以界面里凡是"展开/收起/调序/改名"都用**点按或按钮**实现，别指望更花哨的交互。
